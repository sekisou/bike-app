# バイク安全運転支援アプリ - セットアップガイド

## 問題点（既に解決済み✅）
以前、位置情報取得が機能しない問題がありましたが、**HTTPサーバーの実装により解決しました**。

localhostで実行すれば、ブラウザのセキュリティ制限により位置情報APIが自動的に有効になります。

## 使用方法

### 最も簡単な方法（推奨）

**Windows:** `start-server.bat` をダブルクリック

**またはコマンドプロンプト/PowerShellで実行:**
```powershell
cd c:\Users\souta\bike
python server-http.py
```

**その後、ブラウザで以下にアクセス:**
```
http://localhost:8000/bike-parking-finder.html
```

## 機能説明

### 🌍 位置情報取得
- ✅ **自動位置取得** - 「現在地を取得」ボタンでGPS位置を自動取得
- ✅ **手動入力** - 緯度・経度を手動で入力可能

### 🌪️ 風速情報
- 現在の風速と風向
- 強風警報（15m/s以上）

### ⛰️ 傾斜・地形情報
- 標高
- 山岳地帯の判定

### 🌡️ 気象情報
- 気温・湿度
- 天気・降水量
- 雨天警報

### 🛑 総合安全レベル
- ✅ 安全 (スコア80以上)
- ⚠️ 注意 (スコア50-79)
- 🛑 危険 (スコア50未満)

### 🅿️ 駐車場検索
- OpenStreetMapデータを使用
- 周辺10件の駐車場を表示
- 収容台数・有料/無料の情報

## トラブルシューティング

### ❌「位置情報へのアクセスが許可されていません」

**ブラウザ設定を確認してください:**

**Chrome の場合:**
1. アドレスバーの🔒マークをクリック
2. 「サイト設定」をクリック
3. 「位置情報」を「許可」に変更

**Firefox の場合:**
1. アドレスバーの鍵マークをクリック
2. 「接続情報を表示」をクリック
3. 「位置情報を許可」をチェック

**Edge の場合:**
1. 右上の設定（⚙️）をクリック
2. 「プライバシー」→「サイトのアクセス許可」
3. 「位置情報」を「許可」に変更

---

### ❌「GPSが利用できません」

GPSを持たないパソコンではこのエラーが発生します。**手動入力機能を使用してください**：

1. 緯度・経度を手動で入力
   - 例: 東京 → 緯度: 35.6812, 経度: 139.7671
2. 「手動で設定」をクリック

**よく使う場所の座標:**
| 場所 | 緯度 | 経度 |
|------|------|------|
| 東京駅 | 35.6812 | 139.7671 |
| 大阪駅 | 34.7330 | 135.4955 |
| 名古屋駅 | 35.1708 | 136.8816 |
| 京都駅 | 34.9755 | 135.7597 |

---

### ❌「位置情報取得がタイムアウトしました」

1. 再度「現在地を取得」をクリック
2. ネットワーク接続を確認
3. 手動入力機能の使用を検討

---

### ❌「安全情報の取得に失敗しました」

1. インターネット接続を確認
2. ブラウザを更新（F5）
3. 別のブラウザで試す

## 使用しているAPI

- **Open-Meteo API**: 気象データ（無料、登録不要）
- **Open-Elevation API**: 標高データ（無料、登録不要）
- **Overpass API**: 駐車場検索（OpenStreetMapデータ）

すべて無料で利用可能な公開APIです。

---

## セキュリティについて

- このアプリはローカルで実行されます
- 位置情報データはサーバーに保存されません
- すべての処理はブラウザ内で完結
- HTTPサーバーはローカルマシンのみでリッスン

## システム要件

- **Python 3.6以上** がインストールされていること
- **インターネット接続** （気象・標高・駐車場情報取得用）
- **モダンブラウザ** （Chrome、Firefox、Edge等）
